The flagship component. Pill radius by default, with five variants, four sizes, leading/trailing
icons, an `asChild` escape hatch, and a loading state.

## Rounded

Pill (`full`) is the default; `lg` and `md` are available when you want softer corners.

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `primary \| secondary \| outline \| ghost \| destructive` | `secondary` |
| `size` | `sm \| md \| lg \| icon` | `md` |
| `rounded` | `full \| lg \| md` | `full` |
| `leadingIcon` | `ReactNode` | — |
| `trailingIcon` | `ReactNode` | — |
| `loading` | `boolean` | `false` |
| `asChild` | `boolean` | `false` |

## Usage

```tsx
import { Button } from "@mxv/ui";

<Button variant="primary" size="lg">Get started</Button>;
```
